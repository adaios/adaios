# 交互走查检查清单（UX）

| # | 检查项 | 判定 |
|:-:|:-------|:----:|
| U1 | 输入→发送→AI 处理→展示 全链路每步有状态反馈（无静默等待）| PASS/FAIL |
| U2 | 卡片状态机四态转换无卡死态；waiting 超时有复位 | PASS/FAIL |
| U3 | 失败/降级/重试/删除 都有反馈；无静默吞错 | PASS/FAIL |
| U4 | 异步操作有进度/占位（上传进度、生成中）| PASS/FAIL |
| U5 | 双端（app/web）同一流程行为对拍（降级策略一致）| PASS/FAIL |
| U6 | 键盘收起、手势切换无误触、无丢输入（草稿保留）| PASS/FAIL |
| U7 | 时间线/Feed 聚合：一次输入=一个事件；跨天/多轮边界无重复无丢失 | PASS/FAIL |
| U8 | 空态有引导；错误态人话可理解 | PASS/FAIL |
| U9 | 删除操作有确认；删除后关联（记忆/卡片）一致清理 | PASS/FAIL |

| U10 | 所有 ApiService 请求有超时（建议 15s），超时后卡片复位 idle/ended 且保留重试 | 请求无超时（走查 P1-W6，2026-08-15）|
| U11 | 双端修复对拍固定项：状态机四态/图片失败重试/删除确认/全图 Dialog 四项逐端对拍 | 值复制漂移（走查 S-W2，2026-08-15）|
| U12 | 卡片回合版本号：append 递增 + setState 前校验，迟达响应不得覆盖 ended 卡 | 竞态复活 chatting（走查 P1-W6，2026-08-15）|
| U13 | 批量上传循环不得因 !mounted 中断：dispose 后剩余图经根 messenger 提示 | 切 World 丢图（走查 P1-W7，2026-08-15）|
| U14 | 输入草稿跨 World/路由保留（controller 提升壳层或持久化）| 键盘弹起草稿丢（走查 P2，2026-08-15）|
| U15 | 分页合并按 id 去重（Set seen）| 分页重复（走查 P2，2026-08-15）|
| U16 | 删除操作（记录/任务/复盘）统一确认弹窗双端一致 | app 删除无确认（走查 P1-W8，2026-08-15）|
| U17 | 错误态统一组件（错误文案+重试），禁止 catch 后静默 loading=false 落入空态 | 失败伪装空态（走查 P1-W5，2026-08-15）|

| U3-2 | 每个可点击元素有响应（点击有反馈，不"点了没反应"）；stub 应禁用或进入即提示，不先模拟交互再弹「开发中」| 语音 stub 误导（旧 P3/P5，2026-08-15）|
| U6-2 | 账号/切换类「记住上次选择」不得被 URL query 在刷新后覆盖，或覆盖需一次性语义并同步 URL | `?userId=` 刷新回退（P2 #186）|
| U21 | 「图即上下文」类功能进入对话态后原图必须持续可见：active/对话布局顶部固定渲染缩略图（可点开全图）| 图片追问移动端 active 态原图不可见（P1 #208，2026-08-12）|
| U22 | 次级/可降级数据加载必须锁 + 代际令牌（先判锁再递增、finally 无条件复位、旧代丢弃）| web _loadDegradable 无锁（走查 8 官，2026-08-17）|
| U23 | Dialog 内参数快速切换必须代际隔离（旧查询响应不覆盖新参数）| web 历史 Dialog 日期竞态（走查 8 官，2026-08-17）|
| U24 | 写操作成功必须有自然反馈（第一原则文案 toast），禁止静默成功 | web 记录交易成功无反馈（走查 8 官，2026-08-17）|
| U25 | 首载失败 ≠ 空态：loading/失败/真空三分支渲染，失败给错误文案 + 重试 | web Feed 首载失败伪装空态（走查 8 官，2026-08-17）|
| U26 | 错误提示透出后端人话（body.error 优先），禁止一律「请求失败 (code)」| web _extractApiError 丢人话（走查 8 官，2026-08-17）|
| U27 | 图片/媒体回执必须自然化（用 VLM summary 拼对话句），禁止「📷 已记录 N 张」系统文案 | web 图片回执系统标签（走查 8 官，2026-08-17）|
| U28 | 卡片头部不得出现系统视角徽章（记录/提问/领域），第一原则「无第三视角」全端一致 | app/web Feed 卡徽章（走查 8 官，2026-08-17）|
| U29 | 涨跌/盈亏色语义全端统一（红涨绿亏），三端 app_colors 对拍含 darkRed | admin 涨跌色相反缺 darkRed（走查 8 官，2026-08-17）|
| U30 | 「看似生效」的操作必须有服务端持久化或明确失败反馈：左滑删推送/推送开关/确认落库等，杜绝「本地生效、刷新复现」 | 推送左滑删除仅本地 removeWhere（UI/UX 审查 P1-推送2，2026-08-19）|
| U31 | 静默/自动刷新失败不得破坏已展示数据：已有数据时保留旧值 + 非阻塞提示（陈旧角标），全页错误态仅限首屏首载 | app 交易页 30 分钟刷新失败整页错误态（UI/UX 审查 P1-前端1，2026-08-19）|
| U32 | 交易数值口径自解释：价格回显精度与输入能力一致（≤5 位小数）、成功回执告知自动止损、账户总盈亏注明「总资产−本金」口径且本金未设时不给误导数值 | NL 回显截 2 位 / 成功回执不提 -7% 止损（UI/UX 审查，2026-08-19）|
