# Trading Engine — 核心概念（纪律交易体系）

> 本文件定义 trading engine 的**领域概念**——对齐 `knowledge/context/rules.md`（R1-R120）与 `strategy.md`（六步法）的实际内容。**纪律交易**：用规则约束决策、执行纪律、管理情绪，不是程序化下单。

## 核心实体

### 标的（Instrument）
可交易的金融产品（A股为主）。含代码、名称、类型。引擎按代码获取行情、管理持仓。

### 交易记录（Trade）
一笔买卖成交。含标的、方向（买入/卖出）、成交价、数量、**止损位**、**买点类型**、目标价、原因（2026-08-16 数据模型后）。逐笔流水是引擎分析的基础。

### 持仓（Position）
持有某标的的数量与成本。含**入场日期**（首买日，加仓不覆盖）、**止损位**、**买点类型**、**角色**（主仓/副仓/防守/前锋）。引擎据此做规则判定。

### 规则（Rule）
纪律交易的可执行声明，R1-R120 分类：
```
择时 R1-20 → 选股 R21-32 → 买入 R33-50 → 应对 R51-65 → 止损 R66-80 → 仓位 R81-95 → 纪律 R96-120
```

### 买点类型（BuyPoint）
入场方式的战法分类：B1/B2/B3/SB1/暴力特噗/深水炸弹/单针/补票。**决定应对规则**（R120：B1买的人看白线持股，B2/B3买的人 S1 就走）。

### 止损位（StopLoss）
每笔买入必设的离场价（R68 入场即设止损）。核心：只输一根K线（R66）。

### 交易体系（Strategy）
六步法：①择时 → ②选股 → ③等B1 → ④设止损 → ⑤止盈放飞 → ⑥收队。

## 领域概念

### 交易生命周期（持仓状态机）
```
选股 → 买入（设止损/买点）→ 持有
  ├─ 涨 → 卖点/减仓（R120 卖点对应买点 / R51 放飞一半）
  └─ 亏 → 止损离场/清仓（R66 跌破止损位）
→ 复盘（R106 计划 vs 实际判对错）
```

### 止损纪律
- **只输一根K线**（R66）：止损设在进场K线最低价下方，收盘跌破就走
- **入场即设止损**（R68）：每笔必填，缺则违反纪律
- **止损三级别**（R67）：敏感型/趋势型/盈亏比型
- **被套不补仓**（R69）

### 仓位管理
- **分4-5仓**（R81）、**4231阵容**（R82：40防守+30前锋+20中场+10机动）
- **主仓副仓分离**（R84）
- **压力测试**（R71）：连续两个跌停不影响睡觉 = 最大仓位

### 择时
- **活跃市值（0AMV）**：单日≥4% = 新波段开始（R1）；单日跌≥2.3% = 只卖不买（R2）
- 多头区间大胆做 / 空头区间只卖不买（R4/R5）

### 复盘与纪律
- **计划 vs 实际**（R106）：先有白纸黑字的计划（买点/止损/预期），才能判对错
- **复盘五步**（R98）：交易原因 → 执行对照 → 对错判定 → 教训沉淀 → 规则校准

## 概念关系

```
标的 ──交易──► 持仓（含止损/买点/角色）
  │              │
  └──行情──► 规则判定（R66止损/R81仓位/R120卖点）
                │
                ▼
          建议（买入/持有/减仓/清仓 + 规则依据）
```
