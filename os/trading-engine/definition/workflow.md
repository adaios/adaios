# Trading Engine — 工作流（纪律交易 + 引擎运行）

> 本文件定义 trading engine 的**运行工作流**——纪律交易六步法 + 引擎如何执行。构建流程（课程→规则）见 `pipeline/build-course.md`（AGENTS.md 维护）；引擎输出流程（知识→形态）见 `pipeline/build-engine.md`。

## 纪律交易六步法（用户日常场景）

```
①择时 → ②选股 → ③等B1 → ④设止损 → ⑤止盈放飞 → ⑥收队
```

| 步 | 内容 | 引擎怎么帮 | 规则依据 |
|:-:|:-----|:-----------|:---------|
| ①择时 | 判断市场多空区间 | 注入择时状态（活跃市值 OAMV）| R1-R20 |
| ②选股 | 选符合体系的票 | （选股能力待建，当前人主导）| R21-R32 |
| ③等B1 | 等买点出现 | 记录买点类型（B1/B2/B3/战法）| R33-R50 |
| ④设止损 | 入场即设止损 | **买入必填止损位**（2026-08-16 后）| R66-R80 |
| ⑤止盈放飞 | 涨了按卖点处理 | 建议引擎：涨→减仓/放飞提示 | R120/R51 |
| ⑥收队 | 止损/清仓离场 | **真止损判定**：现价<止损→清仓建议 | R66 |

## 持仓生命周期（引擎运行核心）

```
                    ┌── 涨 → 卖点/减仓建议（R120 卖点对应买点）
买入（带止损/买点）→ 持有 ──┤
                    └── 亏 → 止损离场建议（R66 现价<止损 → clear）
                              │
                              ▼
                        复盘（计划 vs 实际判对错，R106）
```

## 引擎运行流程（建议生成）

```
输入（宿主提供）：持仓 + 行情 + 交易记录
      │
      ▼
读知识层（knowledge/context/）：rules + strategy + mistakes
      │
      ▼
规则匹配（engine/rules）：
  - R66 止损判定：现价 < stopLossPrice → clear
  - R81 仓位判定：positionPercent > 上限 → reduce
  - R120 卖点判定：buyPoint 类型 → 持股 or S1 就走
      │
      ▼
输出：建议（买入/持有/减仓/清仓 + 规则依据 + 自然语言理由）
```

## 复盘流程

```
输入：当日交易记录 + 持仓变化 + 计划（原因/止损/买点）
      │
      ▼
对照规则：R106 对错判定（计划 vs 实际）
      │
      ▼
输出：复盘（执行回顾 + 对错判定 + 教训 → 沉淀 mistakes）
```

## 引擎不做什么

- **不程序化下单**（不接券商/交易所，无订单路由）
- **不持有个人数据**（吃传入的持仓/行情，产出建议——独立暴露隐私安全）
- **不做荐股**（规则约束决策，不是推荐）

## 与宿主协作（插件模式）

```
宿主（如 AdaiOS）→ 传入持仓/行情/交易记录 → 引擎 → 返回建议/复盘
                              ↑                        │
                              └──── 用户操作反馈 ──────┘
```

> 独立模式：同一引擎通过 REST/Skill/Agent 输出，见 `pipeline/build-engine.md`。
