## 二、信息架构（IA）

### 2.1 一级导航（**8 区**，顺序即此）

| 序 | 一级区 | 说明 |
|:--:|:--|:--|
| 1 | **持仓** | 只含**持仓中**的标的（原「持仓」区不再包含自选/清仓） |
| 2 | **自选** | 关注但未持有；买点信号列（B1/B2/案例相似度）在此出现 |
| 3 | **清仓** | 已了结；含「卖掉之后到现在」列与规则对照 |
| 4 | **资金** | 一页三段：自证条（现金 / 可用 / 可取 / 本金 / 账实）→ 资金曲线（现金 / 净值可切）→ 流水表 |
| 5 | **规则** | 我的规则（自建 / 从你的数据里长）+ 我的交易规则（参数表）；**活跃市值（指南针）区间条落此区** |
| 6 | **分析** | 页内 chips：这一笔 / 这只票 / 这一段；默认落「这只票」且**默认带当前持仓第一只** |
| 7 | **案例** | 页内分段：等你认 / 已收下（候选卡 + 已收表格） |
| 8 | **计划** | 次日一句话（+ 自我约束，保留） |

**旧 9 Tab → 新 8 区**：持仓 / 自选 / 清仓 各自独立（不再合并）；资金 + 历史成交 → **资金**；分析 / 规则 / 案例 / 计划 保持；记录交易 · 复盘 · 复盘历史 · 推送设置 → **动作**（常驻顶栏 + 右上角）。

### 2.2 二级导航：**全部取消**

- 侧栏二级（如「资金 / 流水 / 对账」）是旧 9 Tab 收编的残留，**一律取消**；
- 需要分片的地方改**页内分段 / chips**；**计数**挂一级项右侧 badge（`持仓 2` · `自选 23` · `清仓 172`）。

### 2.3 编排（**横 Tab**）

- 一级 8 区用**顶部横向 Tab**（取代交易内竖导航，释放约 135px 宽度）；
- **右侧「阿呆说」栏**：宽屏常驻；**窄窗（<1200px）收为顶栏入口 + 右侧抽屉**；
- 与全局侧栏（对话流 / 记忆 / 时间线 / 待办 / 搜索 / 档案）**不动**。

## 三、交互设计

| # | 决定 | 验收看点 |
|:--|:--|:--|
| I-1 | **打码两层**：数量与成本默认 `••••`；现价 / 止损 / 涨跌% 明文；**分析屏金额纳入 👁**；点 👁 一处解开、全页显形 | 打码态截图 + 显形态截图 |
| I-2 | **表格自适应**：窄窗按可用宽降列（如 <1440 收「近 20 日」）；**操作列冻结在右**；清仓表同规则 | 1280 / 1440 / 1600 三档实拍，操作图标恒可见 |
| I-3 | **K 线：一张图四处共用**（持仓 / 自选 / 清仓 / 案例）——同一组件，外壳统一，差异用参数（context / 数据 / 可选块） | 四处打开同一组件 |
| I-4 | **K 线标记用字母 B / T / S**（B 买 · T 加仓 · S 卖），加大 + 白描边；**补图例行**；弹窗放宽 | K 线弹窗截图 |
| I-5 | **导入 = 右侧抽屉**（不跳页）：拖入 → 认出多少 → 对账结论 → 确认入账 | 抽屉空态 + 预检态 |
| I-6 | **分析屏默认带一只票**（当前持仓第一只；无持仓时给人话空态），不再要求手输代码 | 进屏即见内容 |
| I-7 | **计划 = 次日一句话**（自我约束保留，因早盘推送 `planSection()` 真消费） | 保存与回读 |

## 四、视觉设计

- **涨红跌绿**（A 股口径，三端一致）；
- **高密度密清单**（方向 A「专业终端」）：行高紧凑、数字等宽、强调你的线（止损 / 放飞）；
- **状态条**：6 格（总资产 · 当日 · 总盈亏 · 持仓市值 · 到线 · 账实）+ 副注（仓位 / 现金）；
- **诚实提示**：缺数据不编（显示 `—`）；行情/盈亏不全时**仅异常态**出现小字提示。

## 五、边界（不做 / 不动）

- **不做**：下单 / 执行 / 预测 / 荐股（`X-01`）；用户端行情与活跃市值导入入口（`X-02`）。
- **不动**：全局导航与 Feed（框架约束）；app 端（本稿不含）；后端能力与端点（本批零改动）；admin。

## 八、自评风险

1. **本稿是补做的规格**（决定先于规格两个月/两天发生）——若与前述来源文档有字面差异，**以前述已拍板决定为准**，本稿只负责收拢；

3. **验收依赖真机**：IA / 交互项必须本地真跑比对（不得只跑测试），截图须脱敏。
