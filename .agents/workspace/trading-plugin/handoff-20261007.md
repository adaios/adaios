## 四、必读约束与坑（都踩过）

1. **改结构必然连测试一起改**：`apps/adai-web/test/trading_page_test.dart` 有 162 条用例，**深度耦合旧 9-Tab 结构**（点 Tab、断言区块内文案、Dialog + Tab inline 双份渲染）。9→6 那次红了 28 条，返工三轮才收绿。**折叠区块也会红** —— Flutter `find.text` 默认 `skipOffstage: true`，`ExpansionTile` 收起时子节点被跳过。
2. **有界高度**：`_HistorySection` 内部用 `Expanded`，放进 `SingleChildScrollView`（无界）会每帧抛 `non-zero flex but incoming height constraints are unbounded`。合并区块时，**外框别套无界滚动**，用 `Expanded` 分配高度（现为 资金 22 : 流水 38，工作区 620）。
3. **提交纪律**：**显式路径**，禁 `git add -A`（仓库有并发会话）；pre-commit 会拦三类：`status.md` 测试数漂移 / 端点未登记 `api-spec.md` / `.agents` 新增文件未进 `_index.md`。**改完代码先跑 `flutter test` 再提交**（这是我前两晚返工的根因）。
4. **本地环境**：`apps/adai-web/web/fonts/*.woff2` 是**不入库的手工资产**（缺了中文全缺 + 一排 404）；`data/` 本地**已是生产快照**（原件在 `~/backups/adaios-prod/local-orig-20261007/`）。起环境：`bash .agents/mechanism/scripts/trading-local-up.sh`。
