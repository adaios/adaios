# 交易插件 App 端 · 执行方案

> **给 adai 的读法**：只看 **§四 决策清单**（11 条，每条都有我的默认，回一句「除 X 外按默认」即可）和 **§二 交付物**；其余是主链自跑用的分段与判据。
> **一次性交付**：决策清单一收，主链从「设计规格」一路自主跑到「测试全绿 + 真机走查 + 提交」，**中途不再打断**（除 P0 数据丢失）；**不 push、不部署**。
> **纪律**：讨论与实施分离（改代码从段 2 起）· 审查只报告不直接修（P0 数据丢失除外）· 金额类截图脱敏后才入库。

## 三、范围（钉死）

**做**：① 首屏形态（判断句 · 入账 · 持仓一行+就地展开 · 今天时态区）② 截图入账主线三卡点 ③ 口径可见（现金日期 / 本金置信度 / 账实并入判断句）④ app 收提醒（`R-11`）⑤ 其余四屏收口（收益日历 / 资金 / 推送设置 / 复盘历史）。

**不做**：K 线 / 分析 / 导入 / 规则参数 / 案例 / 画像（web 的全量面）· 任何下单执行按钮 · 改 Feed / Launcher / 底部导航 · 换技术栈（Swift 另立件）· 改后端契约（**唯一例外**见决策门 1 选 B）· 顺手清理无关存量 REVEW 项。

## 五、分段与批次

| **2 实施** | 批 1–4（下表），每批同时补 widget 测试 | 每批：`analyze` 0 error/0 warning · `test` 全绿 · `ai-guard-scope` PASS · 走查该批无 P0/P1 |

**批 1 · 形态骨架**（对 `b 没主心骨 / e 太常规`）：首屏四层 + 指标行折叠 + 两条横幅并入判断句。
验收：进屏 3 秒能答「什么状态 / 有没有事 / 动不动」；5 只票一屏看完；无横幅的日常零占位；判断句**不新增 LLM 调用**（复用 `TradingDecisionNarrator` 口径与确定性数据）。

**批 2 · 截图入账主线**（对 `c 主线不顺`）：卡点①按门 1 路线 · 卡点②异常优先（默认全信 + 可疑项单独醒目 + 指纹/缺日期/价量异常/方向不明/与持仓矛盾五条判据）· 卡点③回执说「这次改变了什么」+ 落账即跑 `GET /trading/integrity` 当场说差额。
红线：**宁可多标可疑，不可放过一笔**（2026-09-13 漏一行＝静默删一只持仓；09-15 重复提交把 600536 记成 1000 股）。

**批 3 · 提醒与随身面**（`R-11`）：推送点开落到「该票/该规则的就地展开」；推送设置屏按 `app-4` 稿收口；web 看依据的口径不变。

**批 4 · 其余四屏 + 两端对表**：收益日历 / 资金 / 推送设置 / 复盘历史按 `app-1..5` 稿收口；与 web 对表（涨红跌绿 · 术语 · 打码两层 · 文案语气）防漂移。

## 六、执行机制（怎么自治）

- **派单一律走收件箱**：任务写 `.agents/workspace/_meta/inbox.md`，`spawn` 的 message 只留一句「按 AGENTS.md 规则开工」（本环境消息通道丢载荷）；3 分钟无落盘＝重派一次，仍无 → 落**档 B**（主链按角色清单执行）并在产物文首标注独立性降级。
- **串行派发**、材料前置、第一动作是 `cp` 模板落文件（变黑盒为白盒）。
- **实施并行度**：不同文件可并行，`trading_page.dart` 同一时刻只一个写者；每批结束先跑守卫再进下一批。

## 七、验收判据（怎么算过）

1. `cd apps/adai-app && flutter analyze` → 0 error / 0 warning；`flutter test` 全绿（当前基线 441 条，只加不减）。
2. `bash .agents/mechanism/guards/ai-guard-scope.sh`（`scope-app` 表逐条有证据）· `ai-guard-align.sh`（测试数/端点对齐）· `ai-guard-meta.sh`。
3. **走查不可被测试替代**：每批真机逐屏实拍，报告写「本轮判定 + 与上轮差异 + 证据」；**点完回读状态再下结论**（本轮最贵的教训，已踩两次）。
4. 形态成立的标准：**首屏第一眼＝「你的规则对照」**（到线没 / 离线多远），资金与涨幅在场但不抢主位。

## 八、前提（需要一次性放行）

1. **放行 `flutter` 命令**（沙箱内写不了 flutter 自身缓存，`flutter test/analyze/run` 都会失败）——已申请 `["flutter"]` 前缀。
2. **放行 iOS 模拟器**（`xcrun simctl` 需连 CoreSimulatorService；本机已有 iPhone 17 Pro 等模拟器）。
3. 本地后端 + `data/` 快照（已在）；`services/adai-core/.env` 已在。
4. **不碰 TestFlight / 生产**：真机确认属发布动作，留到决策门 3 之后。
