# 交易插件概念与流程（按讨论顺序）

> 这份文档**按我们一步步聊的顺序记**——不重排、不提前。还没聊到的，一律挂在末尾「附」，不进主线。
> 口径：定位 / 概念 / 流程是**提议，待你定稿**；涉及代码与现状的地方是**实测**（2026-10-05）。

## 一、定位

### 一句话

**交易插件 = 把你自己的真实交易，变成阿呆对你的理解。**

它只做三件事：**把成交变成账（记录）→ 让账随时对得上（对账）→ 以你的历史为镜照见你的持仓与当下（照见）**。资产是**你自己的记录**。

### 需要你做什么（只有一件不可省）

1. **交出你的真实数据**——**导「资金流水 + 历史成交」**（最少 2 份，见需求文稿 §导入）· 或随手记一笔 / 截图入账。**唯一不可替代的输入**（券商不会把成交推给它）。
2. **（建议）偶尔对一次账**——导持仓股 / 资金股份 做交叉校验。
3. **可选，但决定它帮多深**——定规则、写次日计划、认下它对你的提问。

### 阿呆能帮你做什么

| 层 | 它帮你做的 | 你不用做的 |
|:--|:--|:--|
| **记账** | 成交落成逐笔流水 → 自动推持仓 / 现金 / 成本 / 当日·周·月盈亏 / 资金曲线 | 手工算账 |
| **对账** | 券商真源 vs 系统推导，差在哪只、差多少、为什么，逐笔说得清 | 自己核 |
| **照见·当日** | 收盘复盘——今天到底发生了什么，只讲账上的事实 | 自己回忆 |
| **照见·过程** | 识别「一笔交易」+ 按**你自己的规则**检查 | 自己复盘 |
| **照见·模式** | 行为标注（追高 / 割肉 / 贪心没走 / 套牢死扛…）+ 纪律遵守率 | 自己总结 |
| **照见·铁证** | 每条提醒都带上：你以前这么做结果如何 + 规则原文 + 当时的数字 | 自己去翻 |
| **照见·守约** | 早盘买点提醒 / 尾盘卖点提醒 / 计划执行与「计划外操作」对账 | 定闹钟 |
| **照见·案例** | 把你认过的「完美买点」存下来，未来相似形态问一句「像不像」 | — |

### 它不做什么

不下单、不平仓、不预测、不生成计划、不替你做决定——**建议只输出、不执行**；也不是行情终端。

## 二、规则（一块核心功能）

> **规则不是定位的一部分**——它是这个插件里的**一等公民功能与流程**。

- **为什么需要它**：有了规则，才能判「你守没守纪律」（不然只剩统计，没有对照）。
- **它从哪来（三个来源）**：① **自建**（手填参数 / 对话里一句句确立）② **导入**（一套规则做成可安装的规则包，可选装 / 可改 / 可弃）③ **从数据里长出来**（见 §三）。
- **人人都是规则的制定者**：人人可用 · 人人可新建 · **人人可互相分享**。
- **红线**：阿呆**不能替用户"给"一套交易系统**（那越界成投资建议）——规则只能来自「你给的」或「从你数据里照出来的」。

## 三、没有规则怎么办

- **没有规则 ≠ 不能用**——只少了「规范的那半照见」；**记账 + 客观照见照样成立**。
- **不套默认值**——没有规则时**只说事实**（到成本线 / 有成交 / 持仓变化 /「你没设止损」），**不拿任何默认阈值替你判**（已定 · 2026-10-05）。
- **核心做法：从你的数据里照出来**——

```
你的历史（成交 + 清仓）
   → 描述性分析（你实际怎么做、结果如何）
   → 候选规则（系统提出、每条带据）
   → 你勾选确认 / 你改 / 你直接写（自定义）
   → 成为你的规则
```

- **三态**：**候选**（系统提）→ **已认**（你勾选 / 改）→ **自定义**（你写）；都可改、可弃、可分享。
- **红线**：这是**描述**（你实际在做什么），不是**建议**（你该怎么做）。规则的第一条来路不是"写"，是"照"。

## 四、操作基础数据：清仓股 + 历史成交

| 数据 | 是什么 | 在分析里的角色 |
|:--|:--|:--|
| **历史成交** | 逐笔流水，覆盖**全部操作**（含还持有的、加过仓的） | **权威事件源**——能还原「一笔一笔」（172 条清仓股实际对应 232 笔，即出此源） |
| **清仓股** | 通达信给的**标的级总账**（首次介入 → 末次清仓，累计买卖） | **现成的已了结摘要 + 独立交叉校验**（它把同一只票的多笔合并了，只能当摘要、不能当真相） |
| （持仓股） | 当前还持有的 | 「正在进行的那一笔」 |

> 分析吃**历史成交**（能还原逐笔），清仓股作交叉印证。
>
> **后续更新（2026-10-05 稍后）**：又发现通达信**「资金流水查询」**——一份里含**成交 + 资金事件（转账 / 股息 / 税 / 利息）+ 余额**，且**闭环自证**。结论落在**需求文稿的「导入」节**：**资金流水 = 资金侧主源** · **历史成交 = 成交维度（必导第 2 份）** · **持仓股 = 建议（兜送股 + 对账基线）**。

## 五、数据从哪来

| 数据 | 谁导 | 进哪 | 说明 |
|:--|:--|:--|:--|
| **行情**（全 A 日线包 · 通达信） | **admin** | `data/market/`（全局公共资产） | **不下放客户端** |
| **活跃市值**（指南针指标） | **admin** | 同上口径 | 择时的前提；**不下放客户端** |
| **个人账户数据**（**资金流水** / 历史成交 / 持仓 / 资金 / 清仓 / 自选） | **用户自己** | `data/{userId}/trading/`（个人隐私） | 每次盘后导（**最少 2 份：资金流水 + 历史成交**） |

> **红线（已定 2026-10-05）**：行情导入 + 活跃市值导入**都归 admin，不涉及用户**——用户端**不出现**这两个导入入口。
> ⚠️ 现状差异：当前代码里活跃市值是**用户手判**（`PUT /trading/market-stage` 只存单一当前值）；改为 admin 侧导入属**待落地变更**。

## 六、一笔交易的定义

### 定义（已定 · 2026-10-05）

| 阶段 | 定义 |
|:--|:--|
| **开始** | 从**买入**开始；可能**连续买多天**——**首次卖出之前的最后一次买入 = 建仓完毕** |
| **结束** | 陆续卖出，**直到清仓**（持仓归零） |
| **做T** | 某天**先卖后买**（哪怕先清仓再买回）= **同一笔的过程**，不切新笔 |

> **一句话**：**切笔只发生在「跨日的清仓之后」**——日内任何买卖都不切笔（做T）；跨日清仓即这笔结束。

### 两个已定细则

- **建仓完毕**：作为**独立概念**记在每一笔上（首次卖出前最后一次买入的日期），作 R53/R87 类「该涨不涨」观察窗的起点。
- **不做「底仓」特例**：一切以流水为准；识别不出（如只有卖出、没有建仓记录）就**如实说判不了**。

### 边界可以人工介入

**笔的边界是一等对象**，自动给你默认，你随时能改：

- **自动边界**：按上面口径算出来（跨日清仓切 / 日内不切）。
- **人工边界**：在时间线上指定（点某笔买入 →「**从这笔开始算新的一笔**」；或「与上一笔合并」）。
- **优先级：人工 > 自动**——你标了就以你的为准，自动的让位；每条笔可加一句备注。

## 七、图表（怎么表达）

> **一块通用能力，不是一个页面**——同一套画图能力被多个功能复用：**清仓股回看 · 完美买点案例 · 单笔视图**。

- **画什么**：日 K（可复用案例库那套通达信风格的前端重算）+ 成交量 / KDJ / MACD。
- **标记（就三个简单字母）**：**B** = 买（建仓 / 加仓）· **S** = 卖 · **T** = 做T（同日先卖后买，画成一个 T，不拆成 S/B）。
- **叠加（按消费方需要）**：**止损线** · **峰值浮盈线**（清仓股要、完美案例也要）；各消费方**各自再加自己的标记**。
- **时间窗**：默认 **前后各 15 / 30 根**，**不画全部历史**——图只是给"这一笔"上下文的。

## 八、分析总结

### 怎么分析：三个粒度（可钻取）

| 粒度 | 回答 | 看什么 |
|:--|:--|:--|
| **全局** | 我是个什么样的交易者 | 胜率 · 盈亏比 · 盈亏分布 · 平均持有 · 最大单笔亏 · **行为模式六类** · 纪律违反率 |
| **单标的** | 这只票我一共做了几笔、哪笔好哪笔差 | 逐笔列表 + 汇总（总盈亏 / 胜笔 / 平均持有）+ 这只票特有的模式 |
| **单笔** | 这一笔到底发生了什么 | **建仓期** · 持有期 · 峰值浮盈 / 最大浮亏 · 买卖次数 / 做T次数 / 被套加仓次数 · 最终结果 · **命中哪条规则** |

> **先不加"周期"层**（2026-10-05 决定）——三粒度够用。

### 两种性质（必须分开）

| 性质 | 内容 | 谁都有吗 |
|:--|:--|:--|
| **描述**（客观） | 你实际怎么做的、结果如何 | ✅ 人人可用 |
| **对照**（规范） | 拿**你自己的规则**量你守没守 | ❌ 要有规则 |

> 没有规则的人只做**描述**，并如实说「我还没有你的规则，判不了守没守」——**不拿别人的规则替他判**。

### 怎么总结：三段（已定 · 2026-10-05）

1. **事实**：「这一笔峰值 **+9.4%**（就在买入当天）、最终 **−25.9%**，从 07-22 扛到 08-03（9 个交易日），期间买入 5 次」
2. **对照**：「命中 **R55**（盈转亏没走）」
3. **一个提问**：「要把这条固化成你的规则吗？」

### 四条原则（分析层不能破）

1. **可回溯**——每个数字点得进去（它是哪几天、哪几笔算出来的）
2. **不编**——数据不全就空 / 如实说，**不填 0**
3. **带对照**——每个数字旁边要有对照物（你的规则 / 你自己的历史平均 / 你最好那笔）
4. **只陈述**——不评价、不建议

### 出口是规则

分析不是"看完就完了"——**描述性统计就是候选规则的原料**：平均持有 6.5 天 → 候选「短线超期 7 天」；38 次卖出 31 次在 −3% 内走 → 候选「止损 −3%」。**分析 → 候选规则 → 你认**（见 §三）。

### 放哪端（已定 · 2026-10-05）

**分析 / 图 / 明细都在 web**；**app 只给结论入口**——随身那一刻要的是"该不该动"，不是复盘图（复盘是坐下来做的事）。
