# design-uiux 独立设计审核（视觉层）· v1

**轮次**：v1 · 2026-10-08 · **审核**：`ux-visual-reviewer`（subagent · 独立）
**审核对象**：`design-uiux-20261007.md` §二（IA 呈现：8 区横 Tab、badge、状态条、表格列密度）+ §四（视觉口径）
**判什么**：布局层级 · 触达面积 · 可读性（字号/对比度）· 深色模式 · 空态与加载态 · 三端一致（本轮只 web 供图）
**不判**：交互流程与反馈（D-20261008-01）· 代码实现结构（`code-frontend-reviewer`）· 功能该不该做（已拍板）

## 一、结论

**⚠️ 有条件通过 —— 无 P0 · 无 P1 · P2×3 · P3×5（另 5 项证据缺口）**

`design-uiux` §二/§四 的**结构**在实拍里立得住：8 区横 Tab 顺序与 badge 正确（持仓 2 / 自选 23 / 清仓 172）· 涨红跌绿三处语义都对（清仓「+244.61% 红 / 走对了绿 / 走早了红」· 自选与持仓涨跌色一致）· 6 格状态条 + 副注形态成立 · 清仓概览与原型 `web-4` 逐格对应。

**不立得住的是三处**：① 异常提示的**视觉权重倒挂**（通栏琥珀横幅压过主数据，与 A3-3「降为小字」的决策相反）② 色语义**单一真相被稀释**（同一个 `darkGreen` 同时表示「跌」「对上了」「编辑」）③ **0 值带着色**（`+0.00%` 着绿）。三条都不阻断交付，但都直接命中既有检查清单条目，建议随下轮带上。
