# 交易插件 web 端 · 实施清单（2026-10-07 拍板批）

## 批次（建议按序，含依赖）

### 批 1 · 导航结构：一级 8 区 + 横 Tab + 去二级

- **做什么**
  1. 一级导航改为 **持仓 · 自选 · 清仓 · 资金 · 规则 · 分析 · 案例 · 计划**（横 Tab，置于页面标题行下；标题与 Tab 可并作一行）；
  2. **删除交易内左导航**（含其二级）——释放约 135px 宽度；
  3. 「账」区更名 **`资金`**，内容保持一页三段：自证条（现金/可用/可取/本金/账实）+ 资金曲线 + 流水表 + 对账卡；
  4. 原「持仓」区的三视图拆为三个一级区：**持仓**（只含持仓中）· **自选** · **清仓**；
  5. 计数挂**一级项右侧 badge**（`自选 23` · `清仓 172` · `持仓 2`），不用点开就能看见；
  6. 原二级的三处去处：分析粒度 → **页内 chips**（已有，删侧栏重复项）；案例两态 → **页内分段**；资金三块 → **同页三段**。
- **涉及**：`apps/adai-web/lib/pages/trading_page.dart`（导航与各分区）· `apps/adai-web/test/trading_page_test.dart`（**重灾区**：点 Tab、区块文案、分区断言的用例）
- **验收**：8 个一级均可点且切到对应内容；无任何二级；旧 9 个平铺 Tab 的功能**一个不丢**（逐项对照 `uiux-discovery` §十一 的旧 Tab 清单）；计数 badge 正确
- **风险**：历史教训（9→6 那次红了 28 条断言）——本批结构变化更大，**预计大面积红**，必须连测试一起改

### 批 2 · 宽度预算（横 Tab 的配套）

- **做什么**：`hasRail` 阈值由 `maxWidth >= 1080` 上调至**约 1200**（即右栏在更常见的窗口宽度下自动收成抽屉，复用已有的 P3-6 机制）；`<1200` 时顶栏出现「阿呆说」入口。
- **验收**：**1280 视口**下持仓表 9 列**全显示**（本地实拍截图为准）；顶栏「阿呆说」入口在该宽度出现；≥1440 时右栏常驻
- **依赖**：批 1（导航宽度变化后重新测量）

### 批 3 · 表格自适应（D3）

- **做什么**：① **窄窗降列**——按可用宽阈值自动收列（建议 `<1440` 收「近 20 日」；`<1280` 再把「最近的那条线」并进「盈亏」列副行），阈值以实测为准；② **操作列冻结在右**（内容列可横滚，`图 / 批次 / 编辑` 恒可见）；③ 清仓表同规则（其「图」列当前也需横滚）。
- **验收**：1280 / 1440 / 1600 三档实拍，**操作图标始终可见**；数据不丢（降列项在行展开或副行可查）
- **依赖**：批 1、批 2

### 批 4 · K 线统一组件（D5 + D4）

- **做什么**
  1. 抽统一组件（壳）：`标题（按 context：持仓/自选/清仓/案例）· 指标切换 · 图 · 图例行 · 底部（明细或一句话）`，可选块 = 指标明细 / 绩效格 / AI 理解；
  2. **标记改字母 B/S/T**（设计原文口径），加大 + 白描边；同日同向合并保留；
  3. **补图例行**（日 K + 均线 / 你定的止损 / 峰值浮盈线 / B·S·T / 副图口径）；
  4. **弹窗放宽**（现 760；可放大或支持全屏展开）；
  5. 四处调用（持仓 / 自选 / 清仓 / 案例），案例专属块保留。
- **涉及**：`apps/adai-web/lib/widgets/case_kline_chart.dart` · `trading_page.dart`（两处调用点）· `test/case_kline_chart_test.dart` · `test/trading_kline_test.dart`
- **验收**：四处打开的是**同一组件**（标题/图例/宽度一致）；案例的「指标明细 + 绩效三格 + AI 理解」仍在；图上标记为字母

### 批 5 · 分析屏（R1 + R2）

- **做什么**：① 进「分析」默认带**当前持仓第一只**（无持仓时给空态提示，不再要求手输代码）；② 「这只票」视图**嵌入统一 K 线组件**（买卖点图，即原型 web-3 的视觉主体）。
- **验收**：进分析屏即见一只票的图 + 统计；粒度切换走页内 chips；无持仓时空态给人话
- **依赖**：批 4（组件）

### 批 6 · 小尾巴（D1 + R3）

- **做什么**：① 「活跃市值（指南针）」条从持仓屏顶部**移入「规则」区**（与规则参数同区，标注它是提醒/判定的前提）；② 案例屏**补顶部 4 格**（已收下 · 成功/失败 · 本周新增 · 等你认）——若后端无「本周新增」口径，按「缺数据不编」显示 `—` 或改用可得口径（先与 adai 确认）。
- **验收**：持仓屏首屏顶部只剩状态条；规则区可见区间切换；案例屏 4 格在位

### 批 7 · 文档与状态同步
