# 体系自洽性问题记录（2026-10-07）

> **来源**：本次会话（画分支策略 / 流 / 六道防线，共 12 张图）过程中的实测观察。
> **纪律**：**只记录不修改**（边界 B7）——落点与修法待拍板。

## I1 · 体系级材料没有家

- **现象**：本次产物（1 份文档 + 12 张图）全部落在 `docs/ideas/`，而它们**描述的是 `.agents/` 自己**
- **证据**：`workspace/<分支>/` 按分支组织；`_meta/` 语义为「流程问题 / 规范草案」；`rules/assets/_directory.md` 明写「一次性讨论 → `docs/ideas/`」
- **影响**：体系在给自己画图纸，但图纸不在体系里 —— 下次开工的 AI 读不到
- **建议落点**：要么把 `docs/ideas/` 明确定为图纸区，要么在 `.agents/` 下新开一类「体系图纸」（需先改目录契约）
- **状态更新（2026-10-07 当日）**：本次会话内产物已改落在 `.agents/workspace/_meta/ai-context-architecture/`，14 张 SVG + 14 张 PNG 逐个登记进 `workspace/_index.md`，`docs/ideas/` 无残留副本。但**「家」只算缓了一步**——`workspace/` 的语义是「分支在制品、合并后搬走」，而这块图纸是长期资产，正式落点仍需拍板。

## I2 · 引用守卫是单向的

- **现象**：断链能抓（引用 → 文件），反向抓不到（文件 → 是否还有引用；内容是否已过时）
- **证据**：本次多轮改名与替换（删 1 张、L3-1 连换两版），全靠人工核对才把正文引用改净，而 `ai-guard-meta` 全程 PASS
- **影响**：改名 / 搬家是高频操作，滞后引用会静默留存
- **建议**：加「双向引用」判据 —— 正文引用集合 ⇄ 目录实际文件集合，**两个方向的差集都要报**

## I3 · 图片类资产无契约

- **现象**：同目录 `mockups/` 的 png 逐个登记进 `_index.md`；本次只登记 README，守卫仍 PASS
- **证据**：`ai-guard-meta` 的孤儿判据只覆盖 md 文件
- **影响**：图片可以被无声添加，也可以被无声删除
- **建议**：图片资产最小契约（命名 + 所在目录 README 登记 + 与正文引用一一对应）
- **状态更新（2026-10-07 当日）**：本目录 14 张 PNG 已人工逐个登记进 `workspace/_index.md`；守卫本身仍未覆盖图片，建议的契约没变。

## I4 · 无人参与的关卡，静默失效无人察觉

- **现象**：六道防线里 D1 / D2 / D3 没有任何人参与，全靠机制
- **证据**：`rules/assets/ai-context-layer-spec.md` §四记录了「出口位丢失，但 T4 一直静默 PASS」
- **影响**：机制失效时没有第二双眼睛
- **建议**：这类关卡必须配反例回归（`mechanism/guards/tests/` 已有先例）+ 定期「能否被触发」自检

## I5 · 规则没人读 ＞ 规则不够

- **现象**：体系文档自记「11/12 审查官零读取 · skill 调用 0 次」
- **影响**：迭代的第一优先级应是「减」，但最难执行 —— 它要求 AI 主动说「这条该删」
- **建议**：先做度量采集，三个数即可：**资产加载次数 / 守卫拦截次数 / 人工介入次数**；没有数字，「优化」永远是感觉
