## 4. 办理步骤（六步，依据公安办事指南）

1. 备齐 §3 材料电子件。
2. 打开 `https://beian.mps.gov.cn` → 点「**用户登录**」→ 经公安部「互联网+政务服务」平台登录。
3. 账号下**没有关联主体信息**时，先「**新增主体**」并填主办者信息；已有则跳过。
4. 【业务办理】→【网站业务】→【**新办网站申请**】→ 按平台要求填写（字段见 §5）→【提交】。
5. 等**属地公安机关审核**（本项目属地 = 北京公安；通过后平台通知）。
6. 审核通过后：登录平台 →【我的】→【我的网站】→ 选中该网站 →【详情】→【下一步】→ 进入「网站基本信息」页 → 执行「**下载备案编号图标**」与「**复制备案编号 HTML 代码**」（挂载见 §6）。

### 5.2 三类负责人（个人备案可均为本人，但每类都要单独证件照）

| 角色 | 填谁 | 材料 |
|:--|:--|:--|
| 网站负责人 | 本人 | 身份证正反面 + 手持 |
| 网站安全负责人 | 本人 | 身份证正反面 + 手持 |
| **24 小时应急联系人** | **必须是另一个人**（家人 / 同事，不能是你本人）| 该人身份证正反面 + 手持 + 手机号（可加座机）|

> ⚠️ **北京硬性规定：24 小时应急联系人与「法定代表人」不能是同一人**。个人备案时"法定代表人"就是你本人，所以**应急联系人必须换一个人**（家人或同事均可），需准备他的身份证与手机号。
> **2026-09-21 更正**：此前按外地（珠海）办事指南写过「三类负责人可均为本人」——**北京不适用**（依据北京市公安局《计算机信息网络国际联网单位备案表》填写要求）。网站负责人 / 安全负责人仍可为你本人。

## 7. 常见坑

- 公安备案号形如「**京公网安备 1101XXXXXXXX号**」，与 ICP 号（`京ICP备…`）是两套编号，别混、别只挂 ICP。
- 网站名称 / 域名 / 主体三项必须与 ICP 备案**逐字一致**，否则退回。
- 手持证件照最容易不合格：手指遮挡、反光、裁边、模糊 → 重拍。
- 先装「公安一网通办」App 做完实人认证，再开电脑填报；否则登录不进。
- 别找收费「代办」：流程个人可自助，材料齐了就是拍照 + 填表。
- 平台地址别用旧指引的 `www.beian.gov.cn`（那是另一个入口）；本项目两次实测的可用地址是 `beian.mps.gov.cn`。
