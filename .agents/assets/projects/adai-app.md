# 项目资产：adai-app（移动端）——用户视角功能全景

> **定位**：个人日常使用端（手机）。「记录今天，理解过去，帮助未来」。**用户打开 app = 记录/查看今天，一切从"说一句话"开始**。本卡从用户使用角度描述现状（2026-08-15）。

---

## 一、打开 app 会发生什么

```
首次安装/无账号 → 账号选择页（列可用账号，点选进入）
已有账号        → 直接进入「正面主页」（World A：Feed）
```

- 多账号：URL `?userId=` 优先 > 上次用的账号 > 首屏选号
- 切换账号：正面主页左上角人像 → 或背面主页「切换账号」行 → 选号页 → 重建整个界面（数据不串号）

---

## 二、两个主页（World A / World B）与切换

### 正面主页（World A = MainPage）——「今天」

**用户看到**：顶部日期栏 + 一条条卡片（今天的记录/对话）+ 底部输入栏。

| 区域 | 内容 |
|:-----|:-----|
| 顶部 | 日期（如「8/15·周六」）+ 时间线入口（点日期弹出）+ 人像图标（进档案）|
| 中间 | 今日 Feed 卡片流（每一条记录一张卡，可滚动/分页）|
| 底部 | 输入栏（文字 + ⊕ 附件：图片）|

**正面主页能做什么**（用户在"今天"场景）：
1. **记录**：底部输入框打字 → 发送 → 变成一张卡片（阿呆自动判断是"记录"还是"提问"）
2. **提问/对话**：输入问题 → 卡片进入对话态（绿色「对话」标识）→ 阿呆回答 → 可继续追问 → 点「结束对话」→ 沉淀成总结卡
3. **发图**：⊕ 选图（最多 3 张）→ 逐张上传（顶部显示进度 n/m）→ 变成图片卡片（原图可点开全图）→ 图片卡可"提问"（追问图片内容）
4. **操作卡片**：点卡片「⋯」→ 改分类（生活/交易/项目）、删除（确认弹窗）；点「提问」进对话
5. **下拉刷新** / 「加载更早」翻历史
6. **特殊卡片**：待办（action 卡，可点「完成」）、行情卡（交易推送）、简报（早上阿呆的总结）

### 背面主页（World B = Launcher）——「我的/功能柜」

**用户看到**：顶部拖拽条 + 搜索栏 + 一列功能入口 + 底部「标签宇宙」。

| 入口 | 用户看到 | 点击进入 |
|:-----|:---------|:---------|
| 切换账号 | 当前账号名 | 选号页 |
| 关于我 | 称呼 · 风格 | 个人档案页（查看/编辑）|
| 脑瓜子正在装… | 已存 N 条理解 | 记忆页 |
| 时间都去哪了 | 已记 N 条记录 | 时间线页 |
| 阿呆系统 | Kernel·Domain·数据 | 系统仪表盘（⚠️ 待移 admin）|
| 任务 | 待办·进行中·已完成 | 任务页 |
| 交易 | 持仓·记录 | 交易页 |
| 搜索栏 | — | 搜索页（全文检索）|
| 标签宇宙 | 图谱/列表两种视图 | 点标签 → 直接搜索该标签 |

**背面主页切换方式**：
- 正面 → 背面：Feed 区**上滑**（快速上滑）或壳层空白**快速拖拽**（速度>400）
- 背面 → 正面：顶部**下滑** 或 左上返回箭头
- 键盘弹起时输入框区域上滑不切世界（防误触丢草稿）

## 三、每个页面的具体功能（用户视角）

### 记忆页（脑瓜子）
- 打开自动定位到最近有记忆的日期
- 左右箭头翻日（不能去未来）；顶部标签栏按当日标签过滤
- 每条记忆卡：类型徽标（偏好/模式/决策/事实/洞察）+ 情绪图标 + 已取代（划线）+ 待办/已完成
- ⚠️ 待办记忆只能看，不能点「完成」（闭环断裂，待修）

### 时间线页（时间都去哪了）
- 月历视图（有记录的日期显示绿点）+ 左右翻月
- 点选日期 → 当日记录列表（标题/缩略图/标签/时间）
- 点缩略图 → 全图查看
- ⚠️ 与正面主页的日期弹窗（TimelineModal）功能重复（双实现）

### 搜索页
- 输入关键词 → 全文搜索记录/标签/记忆 → 结果带高亮
- ⚠️ 结果不能点进详情（浏览断点，待修）

### 档案页（关于我）
- 展示：称呼/沟通风格/专注领域/协作规则/关注标签
- 编辑：改称呼、风格、领域、规则开关（交易需确认/日常自动处理）、标签增删 → 保存
- ⚠️ 保存成功无反馈（待修）

### 任务页
- 统计行（全部/待办/进行/完成）+ 状态筛选
- 创建表单：标题（必填）/描述/标签/优先级 P0-P3
- 卡片「⋯」：推进状态（待办→进行→完成）、编辑、删除（确认）
- 🔴 编辑 = 新建（bug，待修）

### 交易页（trading 插件）
- 组合快照（总市值/总盈亏/现金）+ 持仓表（代码/名称/数量/成本/现价/盈亏）
- 「+ 记录交易」表单：代码/名称/方向（买·卖）/单价/数量
- 复盘：右上角按钮 → 生成今日复盘 → 弹窗展示 → 「反哺入库」
- ⚠️ 表单 5 字段偏繁琐（用户要求极简化）；价格无 ≤0 校验（待修）

### 账号选择页
- 列可用账号 → 点选 → 确认进入；空态提示「请先在阿呆控制台创建账号」

## 四、用户视角的现状总结（一句话）

**正面 = 说一句话（记录/提问/发图），背面 = 翻一翻（记忆/时间线/搜索/任务/交易/档案）。**
**核心体验：记录今天（正面 Feed）> 理解过去（记忆/时间线）> 帮助未来（待办/任务）。**

## 五、职责边界（app 属权）

| 属权 | 内容 |
|:-----|:-----|
| **app 拥有（写）** | 个人记录/对话/档案/记忆完成/任务/交易记录 |
| **app 拥有（读）** | Feed/时间线/搜索/标签/记忆/持仓 |
| **不属于 app** | 账号创建/禁用/删除、插件门控、数据清理/重建、知识正式入库、系统配置（→ admin）|
| **app 无越界（已验证）** | 仅调 accounts/available + me/plugins ✅ |

## 六、待打磨方向（用户确认）

1. **带图交流**：向 log/ask 学习——带图可记录、可询问，AI 判定（不再只是"图片记录卡"）
2. **交易极简**：表单最少参数 + 正确性校验；详细输入/数据导入归 web
3. **web/app 分工**：web = 详细管理/导入/丰富功能；app = 简单（保持核心）
