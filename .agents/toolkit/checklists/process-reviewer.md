# 流程官审查检查清单（Process / QA）

> 对「做事的方式」，不对产物内容。判据出处见 `../../rules/process/review-driven.md` §8。

## 主检查表

| # | 检查项 | 判定 |
|:-:|:-------|:----:|
| P-01 | 这一轮**派了谁**、**谁实际落盘**——有无「只回报不落盘」或**代笔**？ | PASS/FAIL |
| P-02 | 审核者与作者是否**独立**（不共享上下文，会前各自读）？ | PASS/FAIL |
| P-03 | 单轮是否**只收敛一类**（P0/P1 必修、P2/P3 只登记）？ | PASS/FAIL |
| P-04 | 子代理是否**分段交付**（先骨架再补）——主链有没有观测点？ | PASS/FAIL |
| P-05 | 单轮**耗时**是否异常（>15 分钟无落盘 = 异常）？ | PASS/FAIL |
| P-06 | **轮次纪律**：≤3 轮；超限是否**升级给人**并带分歧摘要？ | PASS/FAIL |
| P-07 | **取值取舍类**是否先升人（没人拍板就继续跑 = FAIL）？ | PASS/FAIL |
| P-08 | 有无**在制品不经登记**（清单 ⇄ 实际漂移）？ | PASS/FAIL |
| P-09 | 改进是否走「**提案 → 守卫 → 人点头**」——有没有角色**自改**自己？ | PASS/FAIL |
| P-10 | 新判据是否**绑定真实事故**（无事故加判据 = FAIL）？ | PASS/FAIL |
| P-11 | 派单是否**串行发出 + 收到回执**（同批并行＝FAIL；无回执还继续等＝FAIL）？ | PASS/FAIL |
| P-12 | **3 分钟闸门**是否执行（到点无文件 / 未更新是否**立刻打断**，而不是续命）？ | PASS/FAIL |
