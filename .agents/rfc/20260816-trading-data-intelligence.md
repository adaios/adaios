# 交易数据智能（自选股买点 → 清仓复盘 → 打分）

> **实施记录（2026-08-16）**：
> - **自选股 ✅**：WatchlistItem + `watchlist.json` + 通达信自选导入（形态/指标提示保留）+ web 区块 + 端点 3 个
> - **清仓股 ✅**：SoldTrade + `sold.json` + 通达信清仓导入（B/S 日期/持仓涨幅）+ 心理标注 + web 区块 + 端点 3 个
> - **资金股份查询 ✅**：现金余额（292.88）+ 精确成本（4 位）→ cashBalance/R81 分母修正 + 端点 1 个
> - **解析器**：`TradingImportParser`（三格式表头定位）
> - **待做**：K 线数据源（kline()）、盯盘买点判定（B1/B2/B3 区域）、清仓 verdict 规则对照、打分系统（完美图）——见 §四 阶段一/三/四

> **方向 RFC**：交易模块三块数据各有大用——**持仓股**（建议引擎，已上线）、**自选股**（盯盘到买点 + 选股眼光打分）、**清仓股**（B/S 复盘 + 心理标注 + 行为模式）。**K 线是核心数据**（当前交易系统主要看 K 线——B1/B2/B3 买点、止损位、卖点全基于 K 线形态）。打分有**完美图参照系**：从历史课程提炼「B1 十张完美图」等形态样本，K 线形态匹配度评分 + 历史数据统计，形成可积累的选股/买点/执行三维评价。

## 一、背景（三块数据 + 现状）

| 数据 | 内容 | 阿呆能干什么 | 现状 |
|:-----|:-----|:-------------|:-----|
| **持仓股** | 当前持仓（代码/数量/成本/止损/买点）| 建议引擎 R66/R81 + 止损/时段推送 | ✅ 已上线（通达信导入 2026-08-16）|
| **自选股** | 关注列表（代码 + 关注理由/期望买点）| 盯盘：现价/K线进入买点区域 → 推送「到买点了」；历史回溯 → 选股眼光打分 | ❌ 未做 |
| **清仓股** | 历史交易（B/S 点 + 心理标注）| 复盘：对照规则判对错（R66 止损执行 / R120 卖点对应买点）+ 个性化错误模式 | ❌ 未做 |

**核心依赖缺口**：`MarketDataSource` 只有现价接口（quote/indices），**没有 K 线**——而当前交易系统（B1 买点、止损位、卖点）全部基于 K 线形态。K 线数据源是自选股买点提示和打分的**前提**。

## 二、目标

1. **K 线数据源**：`MarketDataSource` 扩展 `kline(symbol)`（日 K 起步，可扩分时）——B1/B2/B3 区域判定、完美图形态匹配的基础。
2. **自选股**：导入关注列表 → 盯盘（现价 + K 线）→ 进入 B1/B2/B3/SB1 买点区域 → 推送「到买点了」；选股历史回溯（关注后涨跌）→ 选股眼光打分。
3. **清仓股复盘**：B/S 导入 → 对照规则判对错（R66 止损执行了吗？R120 卖点对应买点吗？）→ 用户标注当时心理（追高/恐慌/贪婪）→ 沉淀**个性化错误模式**。
4. **打分系统**：历史数据 + 完美图样本 → 选股/买点/执行三维评分，积累后反哺。

## 三、方案

### 3.1 K 线数据源（核心依赖，先行）

```
MarketDataSource（接口，已有）
   ├─ quote(codes)    现价（已有，腾讯）
   ├─ indices()       指数（已有）
   └─ kline(symbol)   日 K 线（新增）：日期/开/高/低/收/量 序列
                      实现：腾讯/东方财富免费 K 线接口（东财 push2his 或腾讯 ifzq.gtimg）
```

**用途**：
- 买点区域判定：B1（回调到关键支撑/白线）、B2（二次确认）、B3（追高禁区）——基于 K 线位置关系
- 完美图形态匹配：当前 K 线形态 vs 样本形态（归一化后相似度）
- 复盘：买卖点对照 K 线回顾

### 3.2 自选股（Watchlist）

**数据模型**：`data/{userId}/trading/watchlist.json`
```json
[{"symbol":"600519","name":"贵州茅台","reason":"季报前埋伏","targetBuyPoint":"B1","addedAt":"2026-08-16"}]
```

**盯盘流程**：
```
K 线 + 现价（轮询，可配）→ 买点区域判定（B1/B2/B3/SB1 规则）
   → 命中 → 推送「贵州茅台 到买点了（B1 区域，现价 X，支撑 Y）」→ PushChannel（Feed + 微信）
```

**导入**：web 批量导入（复用通达信解析思路：代码 + 名称 + 关注理由，CSV/粘贴）。

**选股眼光打分**（数据积累后）：
- 记录：关注日期 + 当时价格 → 关注后 N 日涨跌（5/10/20 日）
- 分数 = 关注后表现统计（命中率 + 平均涨幅 vs 大盘）
- 意义：我的"觉得会涨"到底准不准——20+ 笔后有统计意义

### 3.3 清仓股复盘（Sold Trades）

**数据模型**：`data/{userId}/trading/sold/{symbol}.json` 或并入逐笔流水加字段
```json
{"symbol":"000725","name":"京东方A",
 "buy": {"date":"2026-08-01","price":6.04,"buyPoint":"B1","stopLoss":5.4,"reason":"..."},
 "sell": {"date":"2026-08-15","price":5.81,"sellPoint":"S1"},
 "psychology": "套牢后恐慌割肉",   ← 用户标注当时心理
 "verdict": "..."}                ← 阿呆复盘结论
```

**复盘流程**（对照规则判对错）：
```
B/S 点 + K 线回顾 → 逐条对照：
  R66 止损执行了吗？（跌破止损位有没有走）
  R120 卖点对应买点吗？（B1 买 → 白线持股；B2/B3 → S1 就走）
  R53 没涨=错？（该涨不涨有没有处理）
→ 结论：按纪律 ✅ / 违反纪律 ⚠️（哪条）
→ 用户心理标注 → 行为模式统计（"我总在 B3 追高 / 止损总慢半拍"）
```

**行为模式沉淀** → 反哺 `os/trading-engine/knowledge/context/mistakes.md`（个性化错误模式）→ 建议引擎/推送引用你的历史毛病。

### 3.4 打分系统（完美图 + 历史数据）

**完美图参照系**：从历史课程（`os/trading-engine/01-raw` 87 课）提炼形态样本——
- **B1 十张完美图**：B1 买点出现时的理想 K 线形态样本（位置/量价/结构）
- 同理可建：B2 完美图、止损触发图、卖点图

**打分维度**（三维）：
| 维度 | 打什么分 | 依据 |
|:-----|:---------|:-----|
| **选股** | 我关注的票，到买点后涨没涨 | 关注历史 + 后续表现统计 |
| **买点** | 我买的时点，K 线形态 vs 完美图匹配度 | 完美图样本 + 当前 K 线相似度 |
| **执行** | 我有没有按纪律（止损/卖点）| 清仓复盘 verdict 统计 |

**评分流程**：
```
历史 K 线（买点前后 N 根）→ 归一化 → 与完美图样本相似度
   → 匹配度分（0-100）+ 判定解释（"形态 82% 接近 B1 完美图：回调到白线、缩量"）
```

**意义**：把"感觉选得对不对"变成可积累的分数；分数随数据增多越准；反哺选股策略。

### 3.5 与 trading-engine 闭环

```
rules/strategy/mistakes（知识真相源）
   ↑ 反哺（清仓复盘的行为模式、打分的统计结论）
持仓/自选/清仓（你的数据）
   ↓ 消费
建议引擎 / 买点推送 / 复盘 / 打分（能力）
```

## 四、实施阶段

| 阶段 | 内容 | 验收 |
|:----:|:-----|:-----|
| 一 | K 线数据源（`kline()` 接口 + 东财/腾讯实现 + 测试）| 单测覆盖；本地实测返回日 K 序列 |
| 二 | 自选股（watchlist 模型 + 导入 + 盯盘买点提示 + 推送）| 导入自选 → 设定买点 → 触发推送 |
| 三 | 清仓股复盘（B/S 导入 + 规则对照 verdict + 心理标注）| 导入一笔历史交易 → 阿呆给出复盘结论 |
| 四 | 打分（完美图样本提炼 + 形态匹配 + 三维评分）| B1 十张完美图入库 → 对历史买入打分 |

## 五、边界

- **K 线免费源限制**：日 K 免费稳定；分时/盘口实时需付费源（接口已抽象，可换）
- **打分不决策**：分数是参考，买不买永远人决定
- **完美图是参照系不是教条**：形态匹配度是相似度参考，不替代对当下市场的判断
- **数据积累期**：打分需 20+ 笔才有统计意义，先跑机制后看统计
- **心理标注隐私**：清仓心理是个人复盘内容（data/ 隐私保护），不进共享知识
