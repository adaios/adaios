# 交易模块定位重设——从「建议引擎」到「交易记忆」

> **本 RFC 只取代 20260815 的「核心定位」条款**（"不是记账工具，是建议引擎——输出买卖/持仓建议是目的"）。20260815 其余内容（交互重设计、双端分工、说人话）继续有效。
>
> **一句话新定位（用户确认 2026-09-02）**：交易插件是「阿呆 memory 内核在交易域的投影」——**历史成交数据很容易形成记忆，就是对自己交易的理解；用户自行配置规则，可以有另一个角度去看自己的持仓、自选；核心还是积累、形成记忆，来对未来的一些决策提供依据。**

---

## 一、为什么要重设（背景）

| 动因 | 内容 |
|:-----|:-----|
| 合规死结 | 「建议引擎」形态公开化 = 〔2012〕40号公告逐字命中的荐股软件（提供具体品种/买卖时机/价位建议须持牌）——公开 App + 建议 = 违法，熟人圈可开但默认值=adai 体系仍有「内置判断」色彩 |
| 商业化方向 | 用户核心想法是**做工具**（非课程/战绩/人设）；形态 = **B**：个人 AI 记录+记忆为产品核心，交易是付费意愿最强的插件/垂直场景 |
| 哲学统一 | 交易不是外挂的荐股功能，是 AdaiOS 记忆哲学的垂直应用：**记录 → 记忆 → 对话 → 决策依据** 同构；交易域恰好是"理解自己"付费意愿最强、免费替代品最少的场景 |
| 市场空白 | 同花顺给行情、雪球给社区、记账 App 给数字——没人做「把每笔交易变成对你自己的理解、随时间增值」；交易记忆是年尺度资产（案例/标注/打分越积越懂你），换工具 = 全部重建 → 订阅制天然健康形态 |

## 二、新定位与五层记忆模型

**核心命题：交易模块不是给你看报表的，是让阿呆慢慢"懂你是个什么样的交易者"，然后在你持仓、看自选、下决定前，用你的历史跟你说话。**

| 层 | 是什么 | 现有资产（已建） | 记忆形态 |
|:---|:-----|:-----------------|:---------|
| ① 事件记忆 | 你做过什么 | 逐笔流水 `trades/{yyyy-MM}.json`、domain=trading 记录 | 每笔成交 = 交易域的一条记录，进个人记录流 |
| ② 模式记忆 | 你重复什么 | **行为标注六类**（亏损加仓/追高/短线新开/破止损未走/浮盈回吐/短线超期，RFC 20260825）+ 纪律统计 | 阿呆归纳："你 80% 的大亏来自破止损没走" |
| ③ 案例记忆 | 你信什么 | 完美买点案例库（B1/B2/FAILED 双轨 + 后验回填 + 相似度引擎） | 你的"审美样本库"，越积越像你 |
| ④ 规则记忆 | 你总结成什么 | `data/{userId}/trading/rules.yaml`（16 参数）+ `knowledge.md`（用户私有优先，P1-3 白名单） | 你把经验固化成纪律 |
| ⑤ **认知层（缺口）** | 你和它对话 | **不存在** | 阿呆把①②③④串成对「你」的理解 |

> ①②③④ 均已建成（2026-08-30 第三阶段规则化 + 2026-08-31 案例库数据使用方案）；**⑤ 是定位重设后真正要长出来的新形态**——记忆被"用起来"的对话式交互。

## 三、产品形状（第五层长什么样）

### 场景一：持仓——不再是「建议」，是「照见你」

现在：点持仓卡 →「阿呆建议：买入/持有/减仓」。交易记忆版 → 阿呆说的是：

> "这只票你已持有 6 天。**按你的历史**，盈利单平均拿 3.2 天就卖（你的库里 74% 这样），破止损单平均扛 9 天才走。这次你既没卖也没破位——你在打破自己的模式，这是好事，留意。"

主语是「你」，不是「市场」。

### 场景二：自选——不再是「买点信号」，是「你的样本怎么看」

现在：自选 Tab 显示「B1 85%」规则命中。交易记忆版：

> "这个形态跟你库里 20 个盈利案例的相似度 87%。**但你的规则要求缩量确认，今天量比 1.8，不满足**——按你的纪律，这不是你的买点。"

规则引擎 + 案例引擎全保留，**输出从「判决」变「对照」**。

### 场景三：复盘——从单向模板到双向问答

现在：AI 生成当日复盘（五节单向输出）。交易记忆版加一问：

> 你问阿呆："**我为什么总拿不住盈利单？**"——它调你的模式记忆（浮盈回吐标注次数）、案例记忆（卖飞后又涨的样本）、规则记忆（浮盈回吐阈值），回答的是「你」；这份回答本身沉淀成一条新记忆，明天更懂你。

## 四、合规边界（为什么公开形态可行）

**判断标准一条：输出主语永远是「你」，不是「市场」。**

| 能说（自我认知） | 不能说（荐股） |
|:-----------------|:--------------|
| "你过去 20 个 B1 案例在你的库里胜率 X%，本次形态与你历史样本相似度 Y%，按**你自己的规则**，当前接近你的止损位" | "现在买 XX" |
| 自我认知工具（镜子+尺子） | 投资咨询（预言），〔2012〕40号公告命中，须持牌 |

### 公开版种子语义（实施时拍板，本 RFC 只定方向）

现在的规则引擎：无规则用户 → 默认值 = adai 现状（P1-5 降级语义）——新用户等于开箱即用内置 87 课建议体系，荐股色彩回归。公开版安全姿势：

> **默认 = 空规则 + 纯客观执行**（用户自己配参数/导知识；没配 = 记录 + 风控事实提醒，不给买卖判断）。`rules.yaml` 机制不用改架构，改的是**种子语义**：从「默认=adai 体系」改为「默认=用户自建」。
> 熟人圈（L1，当前现实）：给熟人开 trading 时推送开关按用户只开风控（破止损/大跌等客观事实）类，建议类（早盘/尾盘逐票建议、15:10 到买点推送）对熟人关——同为 per-user 开关，零开发。

## 五、工程纪律（设计路线红线）

1. **数字只能系统给，LLM 只准组织语言**——「照见你」输出全部数字（持有天数/占比/相似度/标注次数）代码算好注入，LLM 只把「你的历史」讲成人话。防幻觉 = 防阿呆编造你的过去（先例：简报注入真实持仓快照防 LLM 算错盈亏）。
2. **「理解」客观推导，不靠用户自述**——行为标注由系统从流水+规则判出（不是问"你今天追高了吗"）。记忆可信度建立在「你如实记录 + 系统冷酷推导」上；缺一环，交易记忆退化为自我安慰日记。
3. **合规红线长在产品形态里**——"阿呆只讲你，不讲市场"从措辞与输出结构层落地，建议类动作按钮从代码层消失；合规论证是产品介绍的一句话，不是辩护词。

| 推送默认 | 时段逐票建议、15:10「到买点了」默认开 | 熟人/公开默认关建议类；本人保留（记忆需要事件积累，推送是记录触发点） |

| 案例库 | 相似度只匹配形态 | 深水区：匹配形态 × 你的行为模式（"上次你在这类形态破止损没走"） |
| 行情数据维护 | 仅命令行 `scripts/sync_tdx_data.sh`（SSH 操作，无 UI） | **职责分层：个人数据导入归用户（web 产品端）；全局行情导入归 admin（运维侧）**——app/web 永不出现行情数据导入（见下） |

### 数据职责分层（2026-09-02 补充：admin vs app/web）

| 导入内容 | 数据归属 | 负责端 | 现状 |
|:---|:---|:---|:---|
| 历史成交/持仓/自选/清仓/资金 | 个人 `data/{userId}/` | **web 产品端**（用户自己） | ✅ 已有 |
| 全 A 日线行情包（tdx .day） | 全局 `data/market/tdx/` | **admin / 运维侧** | ⚠️ 仅 `sync_tdx_data.sh`（SSH，无 UI） |

- **判定**：`data/market/` 在 userId 层之外 = 全局公共资产（基础设施），动它归 admin（`role=admin` 门禁先例：/admin/**、/accounts/**）；个人业务数据归用户自己在产品端导入。产品红线：**app/web 永不出现行情数据导入**（个人记录 App 不该让用户理解 K 线数据源）。
- **共享性**：行情全局共享——一份 tdx + 网络源兜底服务所有 trading 用户，行情成本**不随用户数线性涨**（随用户涨的只有 LLM 调用）。
- **瓶颈不是 UI**：卡点 = "人跑 Windows 通达信盘后下载"；趋势 = admin 侧降频/半自动（周级全量即可，近端缺口由网络源兜底——tdx 只到"上次下载日"，KlineService tdx→腾讯→东财自动补），而非给任一端加按钮。
- **欠账教训**：本地 tdx 曾停更 3 个交易日（2026-08-30 → 09-02 未导入），近端全靠网络源兜底——低频全量 + 自选/持仓走网络源是可行稳态。

## 七、非目标与后续

- **非目标**：本 RFC 不排实施；公开版（含种子语义改造、行情数据授权评估）是远期，先跑稳 v1.0.0 自用+熟人（L1）。
- **验证点（做公开版前）**：找 5 个会交易的熟人用起来，盯一个指标——**他们会不会主动回来记录**。会 → 交易记忆付费点有实证；不会 → 公开版无意义。
- **数据授权（公开版前置成本）**：K 线/行情现走腾讯/东财/通达信文件 = 个人免费授权；商用需付费授权或走「用户自导本地数据」形态（`TdxFileKlineSource` 已具备本地文件方案）。
- **哲学外溢**：五层模型与⑤认知层可原样套到健康/学习/项目域（模式记忆 → 认知层），交易是第一个垂直实现。
