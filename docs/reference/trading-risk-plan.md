# 交易风险管理方案

> **定位：** 用户个人交易的风险管理完整方案——「风险前置（risk-first）」模型落地。
> **原则：** 降低回撤优先于追求收益；止损是合同、买入时定死、只紧不松；系统不假设用户先问，买入前后同一套公式兜底。
> **数据基准：** 生产 `data/adai/trading/`（82.156.111.146），清仓 166 笔、账户快照 2026-08-28。

---

## 第一部分：科学框架（四旋钮，按优先级）

```
本金 → ①风险预算 R（单笔亏多少封顶）
     → ②单笔止损位（每仓在哪认赔）
     → ③满仓度 x（同时暴露多少资金）
     → ④止损生命周期（买入定死、只紧不松）
```

**核心公式：** 回撤 ≈ 满仓度 × 止损距离 × 连亏次数。
降回撤优先者先拧 ①③（不依赖预测、直接减暴露），②④ 是执行保险丝。

### ① 风险预算 R——两个可回答的问题 + 一条红线

**主锚：回撤预算法**

```
问题A：账户最多能接受多大回撤？→ D（通常 10%~30%）
问题B：策略最坏连亏几次？→ n = ln(容忍概率α) ÷ ln(1−胜率p)
单笔风险 R ≤ D ÷ n
```

**红线：凯利上限（绝不能超）**

```
f* = (p×b − q) ÷ b     （p 胜率、b 盈亏比、q = 1−p）
实战取 quarter Kelly（f*/4）当红线：R ≤ min(回撤预算, quarter Kelly)
```

**无数据起点档位**：保守 0.5% / 稳健 1%（默认）/ 激进 2%。先保守，20+ 笔真实记录后按数据重估。

### ② 止损位推导——给定仓位，止损机械算出

```
R = 本金 × r
每股可亏 = R ÷ 数量 N
理论止损价 = 成本 − R ÷ N      （等价：止损距离% = R ÷ 单仓市值）
反向用：单仓市值上限 = R ÷ 期望止损距离%
```

- **多仓位**：风险预算按风险平价均分 → 每仓止损自动联动，仓位越多止损越紧。
- **分批建仓（2~3 天）**：成本用加权均价；预算按计划总量实时校验 `(均价−止损)×已买量 ≤ R`；止损全计划统一一个；破位即取消剩余批次。
- **已持仓补设止损**：止损距离 = min(R ÷ 单仓市值, 规则止损上限 5%)，止损价 = 成本 × (1 − 止损距离)。R÷市值超上限说明该仓按预算只能接受更小距离，取上限值（预算更省）；若反推距离过近（现价已接近）则如实提示触发风险。

### ③ 满仓度 + 回撤闸门（降回撤的主旋钮）

| 当前权益回撤 | 总仓位上限 | 动作 |
|---|---|---|
| 0 ~ 5% | 100% | 正常操作 |
| > 5% | 50% | 减仓一半（优先砍浮亏最大的）|
| > 10% | 25% | 只留最强的 1~2 仓 |
| > 15% | 空仓 | 强制休整，等重新站上 |

现金也是仓位；低回撤偏好者常态总仓位 50~70%。

### ④ 止损生命周期——买入时定合同，之后只紧不松

- **买入瞬间**：止损 = max(技术位, 成本 − R÷N)，从此这笔最大亏损被锁死。
- **三种模式**：纯静态（入门）→ 静态 + 移动止盈（保本 → 追踪，推荐）→ 波动率自适应（进阶）。
- **每天更新的是风险账本，不是止损线**：距止损空间、单仓/总敞口、移动止损触发。

### 买入前判定——五问红绿灯（解决「不问就买」）

| # | 检查 | 规则 |
|---|---|---|
| 1 | 止损距离 ≤ 可承受 | 太远 → 放弃或等更近入场点 |
| 2 | 单笔风险 ≤ R | 超 → 系统直接给建议股数 |
| 3 | 买后总仓位 ≤ 上限 | 超 → 红灯 |
| 4 | 全仓齐跌 ≤ 容忍 | 同板块拥挤 → 减仓 |
| 5 | 回撤闸门未触发 | 降档期不许新开仓 |

买入前跑一遍叫「该不该买」；买入后跑一遍叫「这单站不站得住」——用户问不问，系统都覆盖。

## 校准参数表（数据推出，非默认值）

| 参数 | 取值 | 依据 |
|---|---|---|
| 回撤预算 D | 15% | 当前已 −28.3%，设 15% 防再深亏 |
| 连亏次数 n | 11 | 真实胜率 33% → ln(0.01)/ln(0.67) |
| 单笔风险 R | 本金 × 1% = 1500 元 | min(D/n = 1.4%, quarter Kelly 2.1%) 后保守取 1% |
| 止损距离上限 | 5% | 与 R66 清仓阈值闭合 |
| 单仓市值上限 | 本金 × 25% = 3.75 万 | 规则 positionLimitPercent |
| 总仓位上限 | 70% | 现状 97.7% 必须降 |
| 回撤闸门 | >5% 半仓 / >10% 25% / >15% 空仓 | 低回撤优先 |
| 同时持仓 | ≤ 5 仓 | 规则 + 风险平价 |
