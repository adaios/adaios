## 功能

- **记忆系统进化 Phase 1-5**（`20260801-memory-system-evolution.md`，已 implemented）：
  - Phase 1：记忆类型 `kind`（fact / insight / preference / pattern / decision），按类型召回
  - Phase 2：主题级合并 `topic` + `superseded` + `evolvedTo`——同话题记忆归为一主题，新记忆取代旧版本，回读只取最新
  - Phase 3：actionable 闭环（后端就绪）——Context 回读注入"待行动事项"、Feed 输出 `type=action` 待办提醒、`PATCH /memory/{id}/done` 完成标记；**前端 UI 消费（待办卡渲染 + 完成按钮）列入 v0.2.0**
  - Phase 4：时效淘汰——`lastConfirmed` 回读确认 + 置信度×时效衰减 + 过期清理
  - Phase 5：筛选降噪——无信息增量的 fact 记忆不沉淀
- **产品路线 v1 文档**（`docs/architecture/product-roadmap.md`）：唯一蓝图，路线驱动开发
