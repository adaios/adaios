## 一、按批次止损 —— 编辑闭环（task-log「2026-09-04 交易-批次止损」，P2）

> ✅ **已按推荐实施（2026-09-04 晚间自主批 II）**：P1 方案 A（覆盖层 `lot-stoploss.json`）+ P2 web 批次明细弹窗「✎ 改」止损（app 不做编辑，沿用「去 web」惯例）+ P3 口径自动跟随。见 change-log「按批次止损批」。

### 现状

- 批次止损位 = **买入流水当时带的止损**；没设 → 按你的规则默认止损（default −7%）兜底动态算。
- 破「该批自己的止损」**已单独推送**（批次止损预警，2026-08-25）。
- **缺的**：事后给**单个批次设/改止损**的入口。现有止损编辑只有持仓级 `PUT /positions/{symbol}`（一只股票一个止损位）；且持仓级改止损**只影响底仓（INIT）批**，非初始批不跟随 → 会出现「改了持仓止损，批次预警仍按老线推」的打架。

### P1-批次 数据模型（关键拍板）

批次是纯流水投影（不落盘），非初始批止损锁死在流水里。事后可调需覆盖层：

| 选项 | 方案 | 评价 |
|:--|:--|:--|
| **A（推荐）** | 新增批次级止损覆盖文件 `data/{userId}/trading/lot-stoploss.json`（`lotId → 止损价`），批次推导后合并覆盖 | 不污染流水真相源、可事后任意改、删清仓批次可清理；读取端改一处（effectiveStopLoss 前查覆盖）|
| B | 回写买入流水 `TradeRecord.stopLossPrice` | 污染历史成交（导出/导入/重放会丢或覆盖），不推荐 |
| C | 维持现状只改持仓级 | 不满足「每批独立设/改」需求 |

### P2-批次 入口/展示

- web + app 批次明细弹窗每批加「设/改止损」按钮（弹窗已展示该批止损/破线警示）。
- 持仓级编辑弹窗补提示：「持仓止损作用于底仓与整体判定；分批复盘请在批次明细中逐批设置」。
- 买入记录时给该批止损（已有能力，保持）。

### P3-批次 口径跟随

批次止损改后：批次预警推送 / 破止损行为标注 / 复盘/建议自动跟随（统一走 effectiveStopLoss）。

### 影响面

`TradingLotService`（覆盖合并 + effectiveStopLoss 查覆盖）→ `MarketAlertService`（文案「已跌破该批止损」）→ web/app 批次弹窗 → 新端点（如 `PUT /trading/lots/{lotId}/stop-loss`，插件门控同其它交易端点）。

## 二、资金曲线图（task-log「2026-09-04 交易-资金曲线」，P2）

> ✅ **已按推荐实施（2026-09-04 晚间自主批 IV）**：P1 方案 A（累计净值 = 总资产 ÷ 净投入 + 最大回撤副指标；净投入 = 期初投入缺口 + 转账累计——入金出金分段不跳变）+ P2 起点自动取最早流水/转账（无需你提供历史资金日期）+ P3 端点与 web 资金区块图（迷你折线卡，见 change-log「资金曲线批」）。口径细节（净投入缺口含历史 imports/cash 基准）如实记录在 EquityCurveService javadoc。

对标调研（2026-08-29，7 软件）把**权益曲线列 P0 必备**且 AdaiOS ❌ 无；数据原料已齐（流水 + 账户快照 + 转账）。

### P1-曲线 画什么口径

| 选项 | 内容 | 评价 |
|:--|:--|:--|
| **A（推荐）** | **累计净值曲线**（总资产 ÷ 期初本金，或按 TWR 收益率连乘——出入金不干扰）+ 副指标**最大回撤** | 真实反映交易能力，是资金曲线灵魂 |
| B | 总资产绝对值曲线 | 直观但出入金跳跃失真 |
| C | A + B 双线 | 更全，工作量稍大 |

### P2-曲线 数据起点与粒度

- 曲线点 = 每日收盘值。数据来源：**有账户快照的历史日期直接用**；快照缺失的早期区间从流水回放补（可追溯到你最早记录/导入的日期）。
- 待你确认：**你的资金快照/转账/首次持仓最早从哪天开始**（决定曲线起点；历史成交导入 + sync 后通常可推到第一笔）。

### P3-曲线 端点与 UI

- 后端 `GET /trading/equity-curve?from=&to=`（插件门控；按日聚合返回 `[{date, totalAssets, netValue, drawdown}]`，交易日才有值）。
- web 交易页「资金」区块挂图（复用案例 K 线绘图三区思路：主图净值 + 回撤副图）；app 账户卡可选折叠展示。

### 影响面

新增聚合服务（流水重放 + 快照并集）+ 一个 GET 端点 + web 图表 + api-spec；本地验证用真实数据（你有完整流水）。
